2
YouTube Data API v3 활성화
API 및 서비스 → 라이브러리 → YouTube Data API v3 → 사용 설정
3
OAuth 동의 화면 설정
API 및 서비스 → OAuth 동의 화면 → 외부 선택 → 앱 이름/이메일 입력 → 저장
4
OAuth 2.0 Client ID 발급
사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 웹 애플리케이션 선택
5
승인된 JavaScript 출처 추가
승인된 JavaScript 출처에 아래 주소 추가 후 저장:
https://plenilune40-lang.github.io

Analytics — 노출·CTR·시청시간 분석
Apps Script 웹앱 URL을 한 번만 설정하면 버튼 하나로 Analytics 데이터를 바로 불러와요.
1
Google 스프레드시트 새로 만들기
sheets.new 접속 → 새 시트 생성
2
확장 프로그램 → Apps Script 열기
상단 메뉴 → 확장 프로그램 → Apps Script 클릭
3
스크립트 코드 붙여넣기
기존 코드 전체 삭제 후 아래 다운로드한 코드 붙여넣기. SHEET_ID와 CHANNEL_ID 수정 필수!
4
서비스 추가: YouTube Analytics API
왼쪽 서비스(+) 클릭 → YouTube Analytics API 추가 → YouTube Data API v3도 추가
5
웹앱으로 배포
배포 → 새 배포 → 유형: 웹앱 → 액세스: 본인만 → 배포 → 웹앱 URL 복사
6
아래에 웹앱 URL 붙여넣기
복사한 URL을 아래 입력창에 붙여넣고 저장!
